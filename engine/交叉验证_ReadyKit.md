# 交叉验证记录：与 ReadyKit（最强竞品）同一场景对照

- 时间：2026-09-13 凌晨
- 方式：浏览器实际驱动 readykit.online/cn/salary-calculator/，与本工具引擎（tax-engine.mjs）计算同一场景，逐项比对
- 证据：`01_产品/交叉验证_ReadyKit_截图.png`（ReadyKit 结果页原样截图）

## 场景

上海 · 劳动合同月薪 30,000 · 五险计费基数 30,000 · 公积金计费基数 30,000 · 公积金比例 7% · 专项附加扣除 0 · 无年终奖

## 结论

1. **五险一金逐项、全年实发合计与最强竞品分毫不差**——本引擎的核心计算获得独立第三方实现的交叉验证。
2. **发现 ReadyKit 自身的展示矛盾**：其"每月实发 22,775"×12 = 273,300，与其同页"全年实发合计 266,520"不一致，差额 6,780 元。其月度个税 1,975 元恰等于 237,000×10%（对全年应纳税所得额按单一 10% 档直接乘算、未按 3%/10%/20% 累进与速算扣除），疑为其月度视图未按累计预扣法全年口径平滑。本工具的"平均月到手 ×12 = 税后年总包"由不变量测试强制约束，不存在此类矛盾。
3. **数据时效优势**：ReadyKit 页面显示上海基数"¥7,460–¥37,302"并标注"2025 最新社保数据"；本工具使用 2026-08-18 官方公告的 7,546–37,731。最强竞品当前的数据同样滞后于官方公告，印证"数据新鲜度是现存差异点"（市场验证报告 C 的判断）。

## 附：本工具同场景输出（上海 30k×12，无年终奖）

- 税后年总包：266,520 元；平均月到手：22,210 元
- 全年个税：30,480 元（累计预扣法；应纳税所得额 237,000 落 20% 档）
